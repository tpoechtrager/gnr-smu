# Ryzen 9 9950X3D support

This profile uses PM-table version `0x620205`: 2452 bytes, 613 little-endian
`float32` values, and 16 physical cores. Shared sensor, limit, rail, and
control behaviour is described in the [Zen 5 X3D overview](README.md).

## Per-core telemetry

| Display or export field | Float indices | Count | Unit |
|---|---:|---:|---|
| Core power | `d[301..316]` | 16 | W |
| Core voltage | `d[317..332]` | 16 | V |
| Core temperature | `d[333..348]` | 16 | °C |
| Core frequency | `d[349..364]` | 16 | GHz |
| Core activity metric (exporter) | `d[365..380]` | 16 | metric |
| Core C0 residency | `d[381..396]` | 16 | % |
| Core CC1 residency | `d[397..412]` | 16 | % |
| Core CC6 residency | `d[413..428]` | 16 | % |
| Per-core boost-limit field (exporter) | `d[445..460]` | 16 | GHz |

Core frequency is displayed in MHz. The **Core residency** dashboard group
contains the direct C0, CC1, and CC6 residency lanes as well as their CCD
averages. The separate **FIT / related metric** group displays the global
FIT-related field at `d[16]`; no per-core FIT lane is mapped for this format.

## Temperature telemetry

| Display field | Source | Unit |
|---|---:|---|
| Per-core temperatures | `d[333..348]` | °C |
| CCD0 L3 Cache | `d[595]` | °C |
| CCD1 L3 Cache | `d[596]` | °C |
| CPU CCD0 | SMN `0x59B08` | °C |
| CPU CCD1 | SMN `0x59B0C` | °C |

Tctl/Tdie, IOD lanes, and thermal status are shared direct-SMN sensors and
are listed in the [Zen 5 X3D overview](README.md).

| Display or export field | Source | Unit |
|---|---:|---|

| CPU Core Power | `d[20]` | W |

| VDD18 Power | `d[23]` | W |
| CPU Socket Power | `d[26]` | W |
| CPU EDC | `d[64]` | A |
| Core Power Sum | sum of `d[301..316]` | W |
| VDD_MISC | `d[58]` | V |
| VDDCR_SOC | `d[83]` | V |
| CLDO_VDDG_IOD | `d[259]` | V |

| CLDO_VDDP | `d[269]` | V |
| iGPU Power (PM candidate) | `d[107]` | W |
| iGPU Clock (PM candidate) | `d[108]` | MHz |

| iGPU Utilization (PM candidate) | `d[110]` | % |

`d[186]` remains unidentified. The d[105]/d[106] voltage and temperature
candidates are PM-table mappings; no separate iGPU SMN address is currently
validated.

## Curve Optimizer

Per-core Curve Optimizer uses MP1 message `0x35`. The command argument carries
the CCD/core selection together with the signed 16-bit margin.
