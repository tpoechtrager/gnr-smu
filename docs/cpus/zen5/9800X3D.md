# Ryzen 7 9800X3D support

This profile uses PM-table version `0x620105`: 1828 bytes, 457 little-endian
`float32` values, and eight physical cores. Shared sensor, limit, rail, and
control behaviour is described in the [Zen 5 X3D overview](README.md).

## Per-core telemetry

| Display or export field | Float indices | Count | Unit |
|---|---:|---:|---|
| Core voltage | `d[309..316]` | 8 | V |
| Core temperature | `d[317..324]` | 8 | °C |
| Core frequency | `d[325..332]` | 8 | GHz |
| Core power | `d[333..340]` | 8 | W |
| FIT-related metric | `d[341..348]` | 8 | metric |
| Core CC6 residency | `d[349..356]` | 8 | % |
| Core activity metric | `d[357..364]` | 8 | metric |
| Per-core boost limit | `d[373..380]` | 8 | GHz |

Core frequency is displayed in MHz. The dashboard derives per-core and CCD
C0 activity/load estimates as `100 - CC6`; this profile has no separate C0 or
CC1 residency lanes.

The **Core residency & FIT** dashboard group contains the per-core
FIT-related metric, C0 activity/load estimate, and CC6 residency values. The
raw JSON snapshots preserve these PM-table values by float index, while the
named CSV export exposes the core activity metric and per-core boost limit as
named columns.

## Temperature telemetry

| Display field | Source | Unit |
|---|---:|---|
| Per-core temperatures | `d[317..324]` | °C |
| CCD1 L3 Cache | `d[448]` | °C |
| CPU CCD1 | SMN `0x59B08` | °C |
| CPU Hotspot (exporter) | `d[270]` | °C |
| Slow temperature field 0 (exporter) | `d[298]` | °C |
| Slow temperature field 1 (exporter) | `d[299]` | °C |

Tctl/Tdie, IOD lanes, and thermal status are shared direct-SMN sensors and
are listed in the [Zen 5 X3D overview](README.md).

## Power and additional exporter fields

| Display or export field | Source | Unit |
|---|---:|---|
| CPU Socket Power | `d[20]` | W |
| CPU Core Power | `d[20]` | W |
| Core Power Sum | sum of `d[333..340]` | W |
| CPU SoC Power | `d[21]` | W |
| VDDIO MEM Power | `d[22]` | W |
| VDD18 Power | `d[23]` | W |
| SoC telemetry field (exporter) | `d[87]` | metric |
| SoC telemetry scale field (exporter) | `d[95]` | unit |
| iGPU Power | `d[107]` | W |
| iGPU Clock | `d[108]` | MHz |
| Package energy field (exporter) | `d[212]` | J |
| iGPU Utilization | Not mapped for this profile | % |
| iGPU/GFX Voltage | Not mapped for this profile | V |
| iGPU Temperature | Not mapped for this profile | °C |

The current validated PM mapping for `d[105]`, `d[106]`, and `d[110]` is limited
to the 16-slot `0x620205` format. `d[49]` is Vcore P1, not an iGPU voltage
field. `d[186]`/`d[187]` are not Busy/Idle.

## Curve Optimizer

Per-core Curve Optimizer uses MP1 messages `0x50..0x57`, one message per core,
with a signed 32-bit margin argument.
